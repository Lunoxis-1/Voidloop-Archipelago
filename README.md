# Voidloop-Archipelago-v0.0.1

An implementation of the Archipelago Randomizer for Voidloop

# Current Known Issues
- Game crashes when closed. This has no functional impact.

# Voidloop Archipelago Setup Guide

## Required Software
- Archipelago
- Voidloop (Available on Steam)
- Bepinex (Tested on Vepinex v5.4.23.5, [Available here](https://github.com/BepInEx/BepInEx/releases#release-v5.4.23.5))

## Setup Steps
1. Install the .apworld
2. Install Bepinex into Voidloop. Don't forget to run the game once to generate the required folders!
3. Install the Voidloop Archipelago plugin into {VoidloopFolder}/Bepinex/Plugins. (Voidloop_Archipelago-0.0.1.zip is the plugin, you will have to unzip it)

More information for step 2 is available at [the guide from Bepinex documentation](https://docs.bepinex.dev/articles/user_guide/installation/index.html).

If everything is working, you will see a prompt to enter the host, slot name, and password when you open Voidloop!

## YAML Generation
Use the Options Creator in the Archipelago app to create your .yaml file.

# Randomization Info
Total check count: ~200

## List of check locations:
- All pickaxe, wword, player, and ability upgrades.
- All achievements
- All hats
- The floor 20 gem of each region

## List of items that can be recieved:
- All pickaxe, wword, player, and ability upgrades.
- Skill points
- Random loot (chest loot, golden chest loot, voidrock)
- Region gems (progressive)

## Goal
Obtain the Voidgem, craft the Void Key, and reach level 20 of the Molten Mineshaft to reach The Void!
