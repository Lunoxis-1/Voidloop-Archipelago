# Voidloop-Archipelago-v0.0.1

An implementation of the Archipelago Randomizer for Voidloop

# Voidloop Archipelago Setup Guide

## Required Software
- Archipelago
- Voidloop (Available on Steam)
- Bepinex (See below)

## Setup Steps
1. Install the .apworld
2. Install Bepinex into Voidloop. 
3. Install the Voidloop Archipelago plugin into {VoidloopFolder}/Bepinex/Plugins. (Voidloop_Archipelago-0.0.1.zip is the plugin, you will have to unzip it)

More information for steps 2 and 3 are available at [the guide from Bepinex documentation](https://docs.bepinex.dev/articles/user_guide/installation/index.html).

If everything is working, you will see a prompt to enter the host, slot name, and password when you open Voidloop!

## YAML Generation
Use the Options Creator in the Archipelago app to create your .yaml file.
